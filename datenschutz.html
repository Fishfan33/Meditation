Datenschutz

Kurz gesagt: Die App sammelt keine Daten über dich.

Was die App speichert

Nichts. Deine Meditation stellst du nur in deinem Browser zusammen. Wenn du die Seite neu lädst oder schließt, beginnt eine neue. Die App setzt keine Cookies und speichert keine Eingaben.

Vorlesen

Die Texte liest die Computerstimme „Helmut“ von elevenlabs.io vor. Die Aufnahmen sind fertige Tondateien und gehören zur App; sie wurden vorab einmal erzeugt (dafür gingen nur die Texte der Meditation an ElevenLabs in den USA), werden von dieser Seite geladen und liegen danach in der Offline-Kopie. Beim Anhören werden keine Daten über dich übertragen, weder an ElevenLabs noch an andere.

Nur falls für einen Satz einmal keine Aufnahme vorhanden ist, liest ersatzweise die Sprachausgabe deines Browsers bzw. Geräts. Manche Browser erzeugen diese Stimme auf einem Server ihres Herstellers (zum Beispiel Stimmen mit „Google“ oder „Online“ im Namen); dann erfährt dieser Hersteller, welcher feste Text der App gerade vorgelesen wird, und technisch bedingt deine IP-Adresse.

Während der Meditation bittet die App den Browser, den Bildschirm nicht auszuschalten. Dabei werden keine Daten übertragen.

Offline-Kopie und Installation

Damit die App auch ohne Internet funktioniert, legt dein Browser beim ersten Aufruf eine Kopie der App-Dateien auf deinem Gerät ab (Seiten, Programm, Schrift, Symbol). Das sind dieselben Dateien, die jeder bekommt, keine Daten über dich. Gibt es eine neue Version, holt die App sie und fragt dich, wann sie neu laden soll. Die Kopie entfernst du über die Browser-Einstellungen („Website-Daten löschen“) oder, wenn du die App installiert hast, indem du sie deinstallierst.

Kein Tracking

Es gibt keine Statistik- oder Analysedienste, keine Werbung und keine Knöpfe von sozialen Netzwerken. Alle Dateien, auch die Schrift, kommen von dieser Seite selbst und nicht von fremden Servern.

Hosting bei GitHub

Die Seite liegt bei GitHub Pages, einem Dienst der GitHub, Inc. aus den USA. Wie bei jeder Webseite erhält der Server beim Aufruf technisch bedingt deine IP-Adresse. Laut GitHub wird sie aus Sicherheitsgründen gespeichert, auch wenn du kein GitHub-Konto hast. Darauf hat die App keinen Einfluss.

Mehr dazu bei GitHub: Was ist GitHub Pages? (Abschnitt zur Datenerfassung) und die Datenschutzerklärung von GitHub.
